# MediBook

Dự án quản lý và đặt lịch khám bệnh, dự kiến được xây dựng bằng Java theo hướng đối tượng (OOP).

## Mục tiêu

Tạo ứng dụng giúp bệnh nhân tìm bác sĩ và đặt lịch khám; hỗ trợ quản lý thông tin bác sĩ, bệnh nhân và lịch hẹn.

## Chức năng dự kiến

- Quản lý bác sĩ và chuyên khoa.
- Đăng ký, tra cứu thông tin bệnh nhân.
- Đặt, xem và hủy lịch khám.
- Kiểm tra lịch trống, hạn chế trùng lịch.

## Công nghệ dự kiến

- Java
- Lập trình hướng đối tượng (OOP)
- Git để quản lý mã nguồn
